## Featured projects

### AI evaluation and coding agents

- **[AgentEval Studio](https://github.com/rishabhjha91/agent-eval-studio)** — A full-stack coding-agent evaluation tool. It scores saved agent trajectories using configurable criteria for test correctness, scope control, hallucinated imports, and efficiency. Includes a FastAPI backend, React/TypeScript interface, reports, and side-by-side run comparison.
- **[Scientific Python Benchmark Pack](https://github.com/rishabhjha91/scientific-python-benchmarks)** — Reproducible scientific-computing tasks for evaluating model-generated numerical code. Includes specifications, reference solutions, numerical tolerances, edge cases, automated verifiers, and pass/fail reports for linear systems, constrained optimisation, and power iteration.
- **[SWE-bench](https://github.com/rishabhjha91/SWE-bench)** — A fork of the SWE-bench benchmark repository for exploring evaluation of language models on real-world software issues. SWE-bench evaluates whether a model can produce a patch that resolves an issue in an existing codebase. See the upstream [SWE-bench project](https://github.com/SWE-bench/SWE-bench) for benchmark documentation and methodology.

## How I approach evaluation

I prefer evaluations that are reproducible and evidence-based. A typical workflow starts with a clearly specified task, continues through a reference solution and rubric, and uses independent tests and edge cases to verify correctness. I then inspect failures, compare model runs, and refine the task or scoring criteria so the benchmark measures real capability rather than surface-level plausibility.
